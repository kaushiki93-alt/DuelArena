Duel Arena: An Adaptive 2D Combat Game with Dynamic Power-Ups and Player Balancing
Duel Arena is a Java-based 2D local multiplayer combat game for two players on the same computer. The game will include basic player movement, shooting, health, collision detection, a match timer, different arenas, sound effects, and a best-of-three round system. The main feature of the project is Adaptive Player Balancing. It will monitor the progress of the match and, when there is a significant difference between the players, give the losing player a better chance of getting useful power-ups such as a shield or health recovery. This is meant to give the losing player a chance to make a comeback without directly deciding the winner. The project will also include player login, MySQL database connectivity using JDBC, match history, scores, and a leaderboard. The game will be developed using Java Swing and Object-Oriented Programming, with separate modules for players, bullets, power-ups, collision, scoring, rounds, database management, and the user interface. An AI-based announcer is also planned for contextual match commentary. The final aim is to develop a functional 2D combat game while applying Java programming, GUI development, database connectivity, game logic, and adaptive gameplay.
technologies using-Java, Java Swing, Object-Oriented Programming (OOP), JDBC, MySQL
